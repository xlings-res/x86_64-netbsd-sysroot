# x86_64-netbsd-sysroot

NetBSD 10.2 base system sysroot for x86_64-netbsd (amd64): headers, crt objects, libraries and libc++'s std module sources

Assembled from the official base and comp sets (cdn.netbsd.org), checked against the release's SHA512.

Packaged for xlings by the recipe `pkgs/*/x86_64-netbsd-sysroot.lua` of
[openxlings/xim-pkgindex](https://github.com/openxlings/xim-pkgindex), whose
`.agents/tools/` holds the script that assembled it. Each release's
`PROVENANCE.md` (inside the archive) states the upstream files, their digests and every change.
